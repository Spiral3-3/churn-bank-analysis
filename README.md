# churn-bank-analysis
Ce projet vise à élaborer un modèle de classification pour anticiper le départ des clients d'une banque (churn). À partir d'un jeu de données de 12 300 profils , plusieurs algorithmes sont testés et évalués , avec un focus particulier sur la minimisation des pertes financières et l'optimisation des seuils d'alerte pour le métier.
